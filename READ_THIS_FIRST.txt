POROSCOPE STUDIO | VERSION 1.1 (REAL IMAGE CASE STUDY)
==================================================

NEW: A documented real 6061-T6 aluminium micrograph case study, with
original-file verification, three-method segmentation comparison,
threshold sensitivity, attributed analysis and auditable report exports.

IMPORTANT: The original photograph is sourced from Wikimedia Commons
(CC BY-SA 4.0, Bob Clemintime). It is not expert-labelled porosity
ground truth. The app fetches the original when requested or accepts
a user-uploaded copy of the unmodified original PNG. The photographed
bottom scale-bar region is excluded from analysis; no physical size
calibration is assumed. See docs/ALLOY_CASE_STUDY.md for full details.

TO RUN LOCALLY
1. Extract the entire ZIP. Open the PoroScope-Studio directory.
2. Run VERIFY_PROJECT_WINDOWS.bat if you want a file structure check.
3. Double-click START_HERE_Windows.bat to start the local website.
4. Open '6061-T6 case study' in the application sidebar.

TO UPDATE A GITHUB DEPLOYMENT
The new and changed files belong inside the existing repository: app.py,
poroscope/alloy_case.py, poroscope/reporting.py, poroscope/__init__.py,
tests/test_alloy_case.py, docs/ALLOY_CASE_STUDY.md, docs/VALIDATION.md,
README.md, and this guide. Make sure all files have been committed to
GitHub, and wait for the Engineering QA workflow to pass. On Streamlit
Community Cloud, the app redeploys from the default branch.

The code remains independent. This does not certify any material part.
